# cauce-web

> Web pública de [Cauce](https://cauce.dev) — la infraestructura open source europea para agentes de IA.

## Stack

- [Astro 4](https://astro.build) + TypeScript
- [Tailwind CSS 4](https://tailwindcss.com)
- Deploy en [Vercel](https://vercel.com)

## Desarrollo

```bash
pnpm install
pnpm dev
```

## Estructura

- `src/` — código fuente de la web
- `public/` — assets estáticos (logos, og-image, favicon)
- `CLAUDE.md` — contexto del proyecto
- `brand.md` — identidad visual
